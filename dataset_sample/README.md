# Legacy/source-format dataset sample

> **Format notice:** This directory is intentionally preserved as the original
> 24-record train/source sample. Its chat targets use the pre-v6
> `correct_transform` free-text, two-step schema. Reviewers looking for the
> final `v6.net-affine.1` canonical-net schema should use
> [`dataset_sample_v6/`](../dataset_sample_v6/).

A 24-record sample (3 per label × 8 labels) drawn from the training split of a
programmatically generated, math-verified dataset for fine-tuning a vision model to
**diagnose a student's mistake on a two-step geometry transformation**.

## The task
Each image shows a coordinate grid (−10..10) with three polygons:
- **RED** — the pre-image (starting shape)
- **GREEN dashed** — the correct image (where it should land after the intended two-step transformation)
- **BLUE** — the student's submitted answer

Vertices are **numbered in matching order** across all three shapes so the exact
rotation / reflection / translation (and its handedness) is readable.

The model compares BLUE to GREEN and returns a JSON diagnosis.

## Files
- `images/` — the rendered PNGs
- `train_sample.jsonl` — full records (oracle fields: original / correct_transform /
  correct_image / student_transform / student_image / label / hint / …)
- `train_sample_chat.jsonl` — the same records in the legacy model chat format
  (`{id, split, messages}`): user turn = image + instruction, assistant turn = target JSON

## Legacy target (assistant output)
```json
{"label": "...", "correct_transform": ["...", "..."], "hint": "..."}
```

## The 8 labels
`correct`, `reflection_instead_of_rotation`, `rotation_instead_of_reflection`,
`wrong_rotation_angle`, `wrong_reflection_line`, `wrong_translation`,
`opposite_translation`, `completely_wrong`

## How it was made (why the labels are trustworthy)
Every record is generated by (1) building a correct two-step problem on an **asymmetric**
polygon (so the correct transform is unique), (2) injecting a specific error, and (3)
verifying with a pure-math oracle that the independently-computed diagnosis equals the
intended label. Records that don't verify are discarded. No human labeling; the labels
are correct by construction. Fully reproducible from a fixed seed.
